# AI Usage Report

## Tools Used & Use Cases
- **Claude (Anthropic)** — Used at the start of the project to generate the initial
  HTML/CSS/JS template (structure, responsive layout, and interactive features like
  the theme toggle, mobile nav, and time-based greeting). I treated this as a starting
  scaffold, not a finished product — I went through it afterward and changed what was
  needed. I also used Claude again near the end for a final review pass, which caught
  a few requirements the earlier draft had missed.
- **Gemini** — Used to generate my logo image and to help write the descriptions for
  my two featured projects (Breaker and Darsi). I edited this content afterward so it
  accurately reflected my own work and role on each project.
- **ChatGPT** - Used to review work again to make sure all requirements were met

## Benefits & Challenges
**Benefits:**
- AI significantly shortened the process of building this website. Instead of writing
  the full HTML/CSS/JS structure from scratch, I started from an AI-generated template
  and focused my time on personalizing it.
- Gemini gave me a quick, usable logo and a first draft of my project descriptions,
  saving time I would have spent staring at a blank page.
- Having Claude do a final review pass caught mistakes I had missed on my own.

**Challenges:**
- AI did not fill all the assignment's requirements on the first pass — I had to
  personally check the finished site against the assignment brief to find what was
  missing, rather than trusting the AI output was complete.
- The biggest issue was AI oversight: it can miss things, generate content that looks
  right but isn't fully correct, or leave placeholder text in unexpected places. I had
  to be extra cautious and double-check everything rather than assuming the output was
  final.
- Linking the files together correctly (paths between HTML, CSS, JS, and image assets)
  caused a number of issues that the AI could not resolve for me — I had to debug and
  figure that part out on my own by testing the site directly.

## Learning Outcomes
- Learned how the `<meta name="viewport">` tag scales a page to different devices,
  which is a big part of why the site is responsive.
- Practiced debugging file-linking issues myself (paths between HTML, CSS, JS, and
  images) after realizing this wasn't something AI could reliably fix for me.
- Learned to treat AI output as a first draft that always needs verification against
  the actual requirements, not a finished deliverable — checking it caught gaps that
  would have otherwise gone unnoticed.
- Got faster and more comfortable making CSS and content edits directly, since I had
  to go back through AI-generated code and adjust styling and structure myself.

## Responsible Use & Modifications
- The initial HTML/CSS/JS was AI-generated as a template, but I personally added all
  real content (project descriptions, images, contact details) and changed styling and
  structure where needed.
- I used Claude for a final check of the finished site and found it had missed a few
  requirements, which I then went back and fixed myself.
- I caught and corrected AI oversight throughout the process — nothing was submitted
  as-is without being reviewed and, where necessary, corrected by hand.
- The final AI-written project descriptions from Gemini were edited to accurately
  reflect my actual role and contributions on each project.

## Responsible Use & Modifications
- All AI-generated code was read line by line, tested in the browser at
  multiple screen widths, and adjusted where it didn't match my intent
  (e.g., renaming placeholder text, adjusting spacing/colors to my own
  taste, adding code comments in my own words).
- Placeholder project content and images must be replaced with my own real
  projects and screenshots before this is considered a finished portfolio —
  none of the final "About Me" or project copy is presented as final without
  my edits.
- No AI-generated text is submitted as personal reflection without review:
  the sections above were adapted to reflect my actual experience completing
  this assignment.
- Commit history reflects incremental, human-reviewed changes rather than a single AI-generated dump, in line with academic integrity expectations.
